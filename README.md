# Калькулятор по дискретной математике

Интерактивный веб-калькулятор с пошаговыми решениями для 6 классических задач дискретной математики:

1. **TSP — метод ближайшего соседа** + улучшение 2-opt (1-оптимальное)
2. **TSP — метод ветвей и границ** (алгоритм Литтла) с деревом ветвлений
3. **Алгоритм Дейкстры** — кратчайший путь
4. **Алгоритм Прима** — минимальное остовное дерево
5. **Алгоритм Форда — Фалкерсона** (Эдмондса — Карпа) — максимальный поток
6. **Коды Хемминга** — кодирование/декодирование с исправлением ошибки

Каждое решение выводится пошагово в академическом формате — с матрицами, таблицами и формулами, чтобы студент мог **дословно переписать решение в тетрадь**.

## Запуск

Это чистый HTML/CSS/JS — никакого билд-шага не нужно. Но ES-модули требуют HTTP-сервер (file:// не сработает).

### Быстро (Python)
```bash
python -m http.server 5173
```

### Или Node
```bash
npx serve .
```

Откройте `http://localhost:5173`.

```
.
├── index.html

└── src/
    ├── main.js                 # роутинг / навигация

    ├── algorithms/
    │   ├── tsp-nn.js           # ближайший сосед + 2-opt

```

## Принцип алгоритмов

Каждый алгоритм — чистая функция, возвращающая массив шагов:

```js
{
  title: "Шаг 3: Редукция матрицы",
  text:  "Описание шага...",
  matrix: [[...], ...],         // опционально
  table:  { head: [...], rows: [...] },  // опционально
  highlight: { row, col },      // опционально
  graph:  { nodes, edges, active: [...] }  // опционально
}
```

UI рендерит шаги единообразно — моноширинные матрицы, подсветки, кнопка «Копировать».
